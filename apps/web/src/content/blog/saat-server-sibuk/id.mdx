Tamu yang bertanya ke robot biasanya menunggu dua atau tiga detik. Lewat dari itu, mereka mengulang pertanyaan, mengetuk layarnya, atau pergi ke meja petugas. Robot yang diam terasa rusak, meskipun di belakangnya server sedang bekerja keras.

Satu percakapan dengan robot resepsionis kami melewati tiga tahap. Suara tamu diubah menjadi teks, teks itu dijawab, lalu jawabannya diucapkan. Setiap tahap bisa lambat atau gagal, jadi setiap tahap punya cadangan.

## Mendengar

Di pemasangan kami saat ini, suara tamu diubah menjadi teks oleh Whisper yang berjalan di server sendiri. Kalau layanan suara itu belum siap, misalnya modelnya masih diunduh setelah server baru dinyalakan, kios memakai pengenal suara bawaan browser.

Kalau keduanya tidak tersedia, tamu tetap bisa mengetik. Kolom pertanyaan selalu ada di layar.

## Menjawab

Jawaban datang dari model bahasa yang juga berjalan di server kami lewat Ollama. Model seperti itu berat, jadi jumlah panggilan yang boleh berjalan bersamaan kami batasi. Pengaturan bawaannya dua.

Tamu ketiga yang bertanya di saat yang sama tidak disuruh menunggu. Ia mendapat jawaban dari aturan sederhana yang membaca data tempat: ruangan yang disebut, nomor antrean, atau ucapan terima kasih. Kalau pertanyaannya menyebut ruangan, robot langsung menawarkan untuk mengantar. Kalau sama sekali tidak dikenali, robot menyebutkan hal yang bisa ia bantu dan menyarankan bertanya ke petugas.

Aturan yang sama dipakai saat model gagal menjawab atau belum dipasang sama sekali. Jawabannya lebih kaku, tetapi tidak pernah kosong.

## Berbicara

Jawaban diucapkan dengan Piper, juga di server sendiri, dengan suara bahasa Indonesia dan bahasa Inggris. Mulut di wajah robot bergerak mengikuti keras-lemahnya suara itu.

Kalau Piper tidak menjawab, kios memakai suara bawaan perangkat. Kalau itu pun tidak ada, robot menampilkan jawabannya sebagai teks di balon percakapan, dan mulutnya tetap bergerak sebentar supaya tamu tahu robot sedang menjawab.

## Kenapa di server sendiri

Pertanyaan tamu sering menyebut nama orang, keperluan, dan nomor telepon. Dengan model dan layanan suara di server sendiri, percakapan itu tidak dikirim ke layanan pihak ketiga, dan biayanya tidak naik setiap ada tamu yang bertanya.

Harganya adalah perawatan. Server perlu dipantau, model perlu diperbarui, dan pertanyaan pertama setelah lama sepi bisa sedikit lebih lambat karena model dimuat ulang ke memori. Semua itu kami tanggung sebagai bagian dari layanan purnajual.

Anda bisa mencoba percakapannya di demo robot resepsionis. Data tempat di dalamnya contoh, tetapi alurnya sama dengan yang terpasang.
